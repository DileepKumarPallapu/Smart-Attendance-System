## 🌟 Key Features

1. **Official Vel Tech University Branding**:
   - Features official logo assets (`veltech_logo.png`), institutional colors, and formal headers.
2. **Role-Based Portal Authentication**:
   - Dedicated login screens for **Student** (Pallapu Dileep Kumar), **Faculty**, and **Admin**.
   - Strict credential validation with error alerts for invalid logins.
3. **Subject-Locked Faculty Workspace**:
   - Faculty members log in to their assigned course subject.
   - Access controls ensure professors only manage attendance for their authorized courses.
4. **Bucket Class Structure**:
   - Class rosters structured by **Buckets** (e.g. **Bucket 29** with **30 unique enrolled students**).
   - Individual Registration Numbers following Vel Tech format (e.g. `VTU29962 - 24UECS0805 - CSE(AIML)`).
5. **Real-Time Database Synchronization**:
   - Toggling attendance in Faculty mode immediately updates the student database and recalculates attendance percentages.
   - Live warning banners trigger in Student View if marked absent.
6. **1-Click Official PDF Statements**:
   - Export official course registration statements and campus master attendance reports via `jsPDF`.
